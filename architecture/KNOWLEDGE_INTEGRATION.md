# 1. Purpose

This document defines how KingC Software knowledge is structured, accessed and integrated across the company ecosystem.

AI_Knowledge acts as the central source of truth for:

- Architecture.
- Standards.
- Repository information.
- AI employee definitions.
- Development processes.
- Engineering knowledge.

The purpose of this integration is to allow AI systems and future AI employees to understand KingC Software through a structured knowledge foundation.

# 8. Documentation Rules

When knowledge changes:

1. Update the correct source document.
2. Maintain one source of truth.
3. Run Graphify when required.
4. Verify relationships.
5. Commit changes.
