# Purpose

Global Knowledge represents the complete engineering knowledge shared across every KingC Software repository.

Individual repositories remain responsible for their own implementation, documentation and history.

AI_Knowledge provides the relationships between those repositories.

# Graphify

Graphify connects every repository into one searchable knowledge graph.

Each repository contributes its own graph.

Those graphs are merged into the Global Knowledge Graph, allowing new AI engineers to understand the entire ecosystem without reading hundreds of individual Markdown files.
