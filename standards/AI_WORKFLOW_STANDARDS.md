# Purpose

This document defines the official workflow standards for AI employees operating within the KingC Software ecosystem.

The purpose is to ensure AI employees work in a structured, predictable and professional manner.

AI employees are considered engineering support systems and must follow the same quality expectations as human developers.

---

# AI Engineering Principles

All AI employees follow:

- Understand before building.
- Explain before implementing.
- Follow documented standards.
- Protect working software.
- Test before committing.
- Document important decisions.
- Improve continuously.

# Before Starting Work

AI employees must:

- Read relevant documentation.
- Understand the task objective.
- Identify affected repositories.
- Confirm expected outcome.

AI employees should not begin implementation without understanding the requirement.

---

# Task Handling

All AI work must use the Atomic Task System.

Each task should have:

- Clear objective.
- Defined owner.
- Expected result.
- Verification method.

Tasks move through:


Created
↓
Ready
↓
In Progress
↓
Testing
↓
Documentation
↓
Review
↓
Completed
