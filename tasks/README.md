# Purpose

The Tasks section defines the KingC Software Atomic Task System.

Its purpose is to ensure that every piece of work is planned, tracked, completed and verified using a consistent workflow.

The task system provides a repeatable process for both human developers and AI employees.

---

# Task Philosophy

KingC Software follows the principle:

> Small, well-defined tasks produce reliable software.

Every task should:

- Have one clear objective.
- Have one responsible owner.
- Follow the development lifecycle.
- Be verified before completion.
- Leave the repository in a clean state.

---

# Verification Checklist

A task is complete only when:

- Work is finished.
- Testing is complete.
- Documentation is updated.
- Changes are saved.
- Git is committed.
- Graphify has been updated where required.
- Repository is clean.
