# Atomic Task System

## Purpose

The Atomic Task System provides a standard method for planning, assigning and completing work across the KingC Software ecosystem.

Every task should be small, self-contained and independently verifiable.

This approach improves planning, quality, collaboration and AI coordination.

---

# Definition

An atomic task is a single piece of work that:

- Has one objective.
- Has one owner.
- Produces one measurable outcome.
- Can be completed independently.
- Can be verified before completion.

If a task cannot be verified, it is not atomic.

---

# Objectives

The Atomic Task System exists to:

- Improve planning.
- Reduce complexity.
- Increase development quality.
- Enable AI collaboration.
- Improve progress tracking.
- Maintain engineering consistency.

---

# Atomic Task Rules

Every task must:

- Have a clear objective.
- Define expected outcomes.
- Be independently testable.
- Include documentation where required.
- Be completed before starting unrelated work.

Large features should be divided into multiple atomic tasks.

---

# Standard Workflow

Every task follows the same lifecycle.

1. Understand
2. Agree
3. Build
4. Test
5. Save
6. Commit
7. Verify
8. Complete

---

# Completion Checklist

Before a task is complete confirm:

- Work completed.
- Testing complete.
- Documentation updated.
- Changes saved.
- Git committed.
- Repository clean.
- Graphify updated (where applicable).

Only then is the task considered complete.

---

# AI Collaboration

Each atomic task should have one primary owner.

Supporting AI employees may contribute, but ownership remains with the assigned AI employee until completion.

---

# Documentation Requirements

Completed tasks should record:

- Purpose
- Scope
- Outcome
- Documentation changes
- Related repositories
- Completion status

---

# Benefits

Using atomic tasks provides:

- Better planning
- Easier testing
- Clear ownership
- Faster reviews
- Better documentation
- Consistent engineering
- Reliable progress tracking

---

# Engineering Standard

Atomic tasks are mandatory across all KingC Software repositories.

Every repository should use the same workflow to ensure consistency throughout the engineering ecosystem.

---

# Source of Truth
