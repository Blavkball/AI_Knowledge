# AI Knowledge

AI_Knowledge is the central knowledge repository for every KingC Software project.

Its purpose is to provide a single place where AI engineers, human engineers, and future automation systems can understand the complete software ecosystem without needing to search across multiple repositories.

Rather than replacing individual repositories, AI_Knowledge connects them together.

Current repositories include:

- OmniForces
- AI_Workstation
- BlackBall
- Future KingC Software projects

The repository contains:

- Global architecture
- Engineering standards
- AI employee definitions
- Atomic task methodology
- Repository relationships
- Shared documentation
- Global Graphify knowledge graph

This repository should remain implementation-independent.

Project-specific source code belongs inside its own repository.

AI_Knowledge explains how every repository fits together.
